Impressora imprimindo cores erradas: como calibrar perfil ICC

Doutor Impressora · 30 anos de bancada·Maio/2026

Cores erradas em impressão é um dos problemas mais frustrantes em fotografia, design e arquitetura. Quase sempre é calibração — não hardware. 5 etapas pra recuperar fidelidade de cor.

1. Confirme se o problema é a impressora ou o monitor

Antes de calibrar a impressora, garanta que o que você vê na tela é REAL.

  1. Imprima uma página de teste padrão da impressora (Configurações → Manutenção → Imprimir Página de Status).
  2. Compare com referência conhecida (carta de cor, logo de marca conhecida).
  3. Se monitor está fora de calibração, mesmo impressora perfeita parecerá errada. Calibrar monitor primeiro com X-Rite ColorMunki ou Datacolor SpyderX.

2. Reset de fábrica do perfil de cor

Drivers sobrepostos ao longo de anos acumulam configs erradas.

  1. Painel da impressora ou software (HP Smart, Epson Print Layout, Canon PIXMA Cloud Link) → Configurações → Cor → Restaurar Padrões.
  2. Re-imprima teste — geralmente já melhora 70%.

3. Use papel CERTIFICADO da marca

Papel barato muda absorção de tinta — perfis de cor não compensam.

  • Epson SureColor + papel premium Epson = perfil ICC otimizado.
  • HP DesignJet + papel HP Premium Photo = mesmo princípio.
  • Papel "compatível" econômico em foto profissional = sempre cores erradas.

4. Atualize driver e perfil ICC do papel

Perfil ICC = "tradução" entre cor digital e cor impressa.

  1. Site da fabricante (HP, Epson, Canon) → Suporte → Modelo → Perfis ICC.
  2. Baixe perfil específico para o papel que você usa.
  3. Instale no Windows: clique direito no .icc → Instalar Perfil.
  4. Software de impressão: selecionar perfil correto antes de imprimir.

5. Cabeça de impressão limpa + alinhada

Cabeça suja imprime cores irregulares.

  1. Painel → Manutenção → Limpar Cabeças (1-2× se necessário).
  2. Painel → Manutenção → Alinhamento de Cabeças.
  3. Se persistir: serviço técnico — cabeça precisa limpeza ultrassônica (R$ 80-200) ou substituição.

Cores corretas exigem cuidado em 4 frentes: hardware (cabeça), papel (certificado), software (driver atualizado + ICC) e calibração (mensal pra uso profissional). Diagnóstico gratuito — manda foto do problema pelo WhatsApp.
