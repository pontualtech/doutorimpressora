Notebook não liga: 7 causas (do simples ao técnico)

Doutor Impressora·Maio/2026

Notebook que não liga é um dos problemas mais frustrantes. Vamos passar pelas causas em ordem de probabilidade — comece pelo passo 1 e siga até identificar o seu caso.

1. Bateria descarregada + carregador defeituoso (mais comum)

Bateria a 0% + carregador com mau contato = notebook não responde.

  1. Conecte o carregador. LED de carga acendeu? Se SIM → aguarde alguns minutos antes de ligar.
  2. Se LED não acendeu, teste outro carregador (mesmo modelo) ou outra tomada.
  3. Se ainda não acende, o problema é cabo ou fonte — precisa trocar.
  4. É a causa mais frequente em bancada.

2. Hard Reset (descarga estática)

Capacitores carregados travam o boot. Descarga zera tudo.

  1. Desconecte o carregador.
  2. Remova a bateria (se removível) — modelos ultrafinos não removem.
  3. Pressione o botão Power 30-60 segundos consecutivos.
  4. Reconecte bateria + carregador.
  5. Tente ligar.
  6. Procedimento universal — vale tentar antes de pensar em troca de peça.

3. Botão Power emperrado

Após anos de uso, o botão fica preso ou perde contato.

  • Pressione o botão Power várias vezes em sequência rápida.
  • Se o notebook ligar errático, o botão precisa de troca.
  • Sinal: botão "afunda" demais ou não retorna.

4. Tela quebrada (notebook está ligado, mas você não vê)

Notebook funciona, mas o display não exibe nada.

  1. Pressione Power. Ouve som de cooler, ventilação ou HD?
  2. Se sim, o notebook ligou — o problema é a tela.
  3. Conecte um monitor externo via HDMI. A imagem aparece?
  4. Se SIM no monitor: a tela do notebook está com defeito e precisa de troca.

5. RAM defeituosa ou desencaixada

Memória deslocada ou queimada = sem POST.

  1. Acesso técnico: precisa abrir o notebook (geralmente parafusos na parte inferior).
  2. Localize os pentes de RAM (slots SODIMM).
  3. Remova e reinserte com firmeza.
  4. Se houver 2 pentes, teste com 1 só, depois alterne.
  5. Se 1 pente queimou, é necessário substituir.
  6. NÃO tente se não tem experiência — leve para a bancada.

6. HD/SSD travado ou queimado

Notebook liga mas trava em "preparando Windows".

  • Notebook entra na BIOS? Se sim, vá em "Boot order" — o HD é detectado?
  • HD não detectado = queimado ou cabo SATA solto.
  • Solução: substituir por SSD novo + clone do antigo, quando possível.

7. Placa-mãe queimada (último recurso)

Quando passou por todos os passos acima sem sucesso.

  • Sinais: o notebook não dá NENHUM sinal mesmo com carregador OK + RAM OK.
  • Cheiro de queimado: placa fritou (geralmente após pico de tensão).
  • Em equipamento muito antigo, normalmente compensa avaliar comprar um novo.
  • Antes de descartar, vale tentar recuperar os dados do HD.
